# Visual rubric

Score the render 0–2 on each dimension: primary journey/focal point, spacing/proximity, typography hierarchy, alignment/grid, action/state clarity, responsive composition, and context-specific distinctiveness.

When no design system or reference images exist, distinctiveness means coherent, intentional use
of the chosen shipped preset. Do not reward off-catalog palette or component improvisation in that
fallback path.

- `0` — broken or unstyled.
- `1` — competent but visibly weak.
- `2` — polished and intentional.

No zero may ship. The seven-dimension average must be at least 1.5; spacing/proximity, primary journey/focal point, and responsive composition must each score 2. Name screenshot evidence for every score; ungrounded “looks good” critique does not count.
